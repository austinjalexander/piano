# Phase 4 Musical playing

Prerequisites depend on the selected piece. Use repertoire within current reading and coordination abilities so expression receives attention.

- **P4.1 Phrasing and articulation:** phrase direction, dynamic shape, legato, staccato, and a clear musical intention.
- **P4.2 Balance and pedal:** audible melody over accompaniment; clear pedal changes after secure unpedaled work, with an appropriate pedal-equipped instrument.
- **P4.3 Repertoire and retention:** contrasting short pieces, recovery after mistakes, and later maintenance performances.

This is a scope outline; detailed lessons and checks are pending. Select actual editions/arrangements and define audible criteria for each passage. Audio supports sound feedback; video can add movement evidence. Record the limits of the available evidence.
