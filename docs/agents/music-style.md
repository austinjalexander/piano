# Music notation and source conventions

- Use note letters A–G with accidentals where needed. Spell chords according to their musical function; distinguish enharmonic spelling from keyboard location.
- Use scientific pitch notation with **middle C = C4**. State any app/MIDI octave convention differences and comfortable octave substitutions.
- Finger numbers are thumb 1 through little finger 5 for both hands. Label RH/LH; do not imply identical fingering for every hand or passage.
- Specify meter, durations, rests, ties, repeats, and the beat unit for BPM. A bare number such as “60” is ambiguous.
- Plain-text letter patterns are playing recipes. Use actual staff notation for staff-reading objectives, from an accessible source or an original authored score; do not grade staff reading using letter labels.
- Distinguish intended sound from observed results. A generated MIDI, score, or reference recording demonstrates the example, not the learner's performance.
- Cite provider links for resource claims. For local books, record verified title, edition, printed page/PDF page, and bars. A filename does not establish bibliographic identity.
- Keep books, commercial scores, and large recordings outside Git; record exact paths and evidence type in learner records. Use original explanations and short original exercises in the repo.
