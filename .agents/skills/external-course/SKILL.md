# Track an external lesson source

Read `EXTERNAL_COURSES.md`, `STUDY_PLAN.md`, and relevant provider/piece records. Use `templates/external-course-template.md` for a new source; do not create an active course from a mere recommendation.

Verify the actual title/edition and accessible lesson/page/timestamp before assigning specific work. Record login/access limits honestly. Map the task to curriculum IDs and specify what it replaces in the same piano budget.

Save actual activity, assistance, provider status, and the exact resume point. Keep reading/viewing separate from playing evidence and local mastery. When pausing, record a useful return trigger or learner-agreed date; check that queue at planning transitions. Do not enroll, purchase, or message a teacher without an explicit request.
