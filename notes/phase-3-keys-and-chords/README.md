# Phase 3 Keys and chords

Prerequisites: keyboard geography and comfortable separate-hand playing. Accompaniment also needs basic hands-together coordination.

- **P3.1 Scales and keys:** whole/half steps, major patterns, a suitable one-octave fingering, and later minor patterns. Begin with C; add G and F as ready.
- **P3.2 Triads and inversions:** build, play, and listen to major/minor triads and efficient chord changes.
- **P3.3 Accompaniment and transposition:** play a simple I–IV–V–I pattern and move a short melody to another familiar key.

This is a scope outline; detailed lessons and checks are pending. Tie theory to audible keyboard examples and selected repertoire. Set individual comfortable tempos instead of universal speed requirements.
