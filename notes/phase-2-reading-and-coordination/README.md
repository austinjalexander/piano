# Phase 2 Reading and coordination

Prerequisites: keyboard familiarity, basic note values and pulse, and starting grand-staff landmarks from Phase 1. Continue listening practice alongside this phase.

- **P2.1 Separate-hand reading:** connect a short notated phrase with fingering, keyboard position, and rhythm.
- **P2.2 Hands together:** begin with a repeated bass note or sparse accompaniment under a short melody. Simplify the texture before increasing speed.
- **P2.3 Fresh reading:** scan, choose a slow pulse, and play an easier unfamiliar excerpt continuously. Use new material for assessment.

This is a scope outline; lessons and specific checks are pending. Select a readable book/edition or author original material, define the bars, beat unit, preparation, and pass criteria before assessing. Record real evidence in [progress](../../PROGRESS.md).
