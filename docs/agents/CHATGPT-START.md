# Piano study handoff

For a chat without local file access, export the current lesson packet:

```sh
python3 tools/agent_config.py export --module notes/phase-1-foundations/01-keyboard-and-pulse > /tmp/piano-study.md
```

Paste or attach the packet with the current practice log or piece record and the time you have available. The packet excludes the separate solution/rubric file; practice notes still contain instructional examples. Do not use it as a hidden-answer examination environment.

Suggested opening: “Use this piano learning context. Start from my latest attempt, teach one small task at a time, and label what is self-reported versus actually reviewed. Give proposed log updates for me to save.”

Only share recordings you choose to provide. If audio/video inspection is unavailable, use self-reported results and leave unobservable criteria unassessed. The chat must not claim local edits or heard/seen details without the necessary tools and evidence.

Afterward, save actual work and your own reflection in `practice/`, link relevant piece/assessment evidence, and update `PROGRESS.md` only when its criteria are met.
